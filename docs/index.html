A password manager you can read in one sitting.

pwvault keeps your passwords in one encrypted file on your own computer. It never goes online, it has no account to sign up for, and every line of its code is short enough to check yourself.

  • Offline only
  • Argon2id
  • XChaCha20-Poly1305
  • libsodium via PyNaCl
  • Python 3.9+

What it does

Stores logins

Add, list, look up and delete entries. Each one has a name, a username and a password.

Makes strong passwords

Generates random passwords from your operating system's secure random source, with or without symbols.

Copies safely

Puts a password on the clipboard and wipes it after 20 seconds, so it isn't left lying around.

Stays on your machine

One file, ~/.pwvault/vault.json. No cloud, no sync, no network code at all.

How your passwords are protected

Your master password is never stored. It's turned into a key, and that key locks the whole vault. All of the cryptography comes from libsodium, a widely used and well reviewed library. None of it is hand-written.

Slow to guess

Argon2id makes each master password guess cost about 0.4 seconds and 256 MiB of memory, so a stolen file can't be attacked with billions of cheap guesses.

Tamper-evident

XChaCha20-Poly1305 encrypts and authenticates. Change one byte of the file and it refuses to unlock instead of giving back wrong data.

Settings can't be weakened

The readable header (version, salt, Argon2 settings) is authenticated too, so nobody can quietly lower the protection.

Crash-safe saves

Each save writes a temporary file and then swaps it in, so a crash never leaves a half-written vault. The file is readable only by you.

Reveals nothing

Entry names and usernames are encrypted along with the passwords. The file gives away nothing but its size.

Install and use it

You need Python 3.9 or newer. These commands download the code and install the pwvault command.

$ git clone https://github.com/uniquepoudell/pwdvlt.git
$ cd pwdvlt
$ python3 -m venv .venv
$ source .venv/bin/activate      # Windows: .venv\Scripts\activate
$ pip install -e .

Then:

$ pwvault init                         # create the vault, choose a master password
$ pwvault add github -u myname         # asks for the password, hidden as you type
$ pwvault add email -u me@example.com --generate
$ pwvault list                         # entry names and usernames
$ pwvault get github                   # copy to clipboard, cleared after 20 s
$ pwvault get github --show            # print it instead
$ pwvault delete github                # asks before deleting
$ pwvault generate -l 24               # just print a strong password

Every command except generate asks for the master password. Clipboard copying uses pbcopy on macOS, clip on Windows, and wl-copy, xclip or xsel on Linux. Use --vault PATH or PWVAULT_PATH to keep the vault somewhere else.

Limits to know about

Honest about what it can't do.

There is no password recovery

If you forget your master password, the vault cannot be opened by anyone, including you. That's by design. Write it down and keep it somewhere safe offline.

  • Not security audited. This is a learning project. Until it has had a review, keep a well-established password manager for your most important logins.
  • Don't store crypto wallet seed phrases in it. Those deserve offline, purpose-built storage.
  • Back up vault.json. It's safe to copy because it's encrypted. Without a backup, one disk failure loses everything.
  • Your computer has to be trustworthy. Python can't reliably wipe secrets from memory, clipboard history tools may keep copies, and malware such as a keylogger defeats any password manager.
